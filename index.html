Silaturahmi Akbar Paskas Bahagia adalah ajang bertemunya hati para pejuang kebaikan, kafilah sedekah, dan keluarga besar dari penjuru tanah air. Mari daftarkan kehadiran Anda dan rombongan wilayah untuk menikmati kehangatan ukhuwah di tengah sejuknya alam asri.

5 Tahapan Registrasi:

  1. Pilih jenis pendaftaran pada kartu di bawah: Individu (Mandiri) atau Kelompok (Kafilah).

Integrasi Basis Data Cloud Supabase

Sinkronisasi Cloud Real-Time

Aplikasi ini mendukung penyimpanan Cloud Supabase secara real-time. Jika belum dihubungkan, seluruh data pendaftaran tetap aman tersimpan 100% di LocalStorage browser perangkat Anda.

Kredensial API Project
Hubungkan ke database PostgreSQL Supabase
Alur Praktis Integrasi
3 tahapan mudah mengaktifkan Cloud
1 Buka akun di supabase.com lalu buat Project baru.
2 Buka menu SQL Editor di dashboard Supabase, lalu salin dan jalankan skrip SQL di bawah.
3 Salin URL & Anon Key dari Project Settings > API, tempel ke form lalu klik Simpan Kredensial.
Data otomatis disinkronkan saat terhubung ke internet.
Skrip Struktur Tabel Supabase (schema.sql) 
-- Buka Supabase > SQL Editor > Paste & Run skrip ini:
CREATE TABLE IF NOT EXISTS registrations (
  id BIGSERIAL PRIMARY KEY,
  registration_code VARCHAR(50) UNIQUE NOT NULL,
  registration_type VARCHAR(20) NOT NULL,
  group_name VARCHAR(150),
  group_leader_name VARCHAR(150),
  full_name VARCHAR(200) NOT NULL,
  gender VARCHAR(20) NOT NULL,
  wilayah VARCHAR(150) NOT NULL,
  daerah VARCHAR(150),
  email VARCHAR(150),
  phone_number VARCHAR(50),
  emergency_phone VARCHAR(50),
  arrival_date DATE NOT NULL,
  arrival_time VARCHAR(20),
  departure_date DATE NOT NULL,
  departure_time VARCHAR(20),
  transport_arrival VARCHAR(100) NOT NULL,
  transport_departure VARCHAR(100) NOT NULL,
  cloth_size VARCHAR(10) NOT NULL,
  medical_history TEXT,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

Panduan Deployment ke Vercel

Aplikasi ini sudah dilengkapi dengan file vercel.json dan dapat langsung dideploy ke Vercel tanpa kendala build.

  1. Upload folder project ini ke repository GitHub Anda (atau gunakan GitHub Desktop).
  2. Buka vercel.com dan login ke akun Vercel Anda.
  3. Klik "Add New Project" dan pilih repositori GitHub project ini.
  4. Pada Framework Preset, biarkan "Other" (static web). Folder root otomatis terdeteksi.
  5. Klik tombol "Deploy"! Dalam beberapa detik, URL website Paskas Bahagia Anda sudah online dan dapat diakses dari HP & laptop seluruh peserta.
